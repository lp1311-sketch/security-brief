How to read this table

  • CVE links to the Microsoft Security Update Guide entry. That page is the authority for affected products, severity (CVSS) and fixes. The feed used here does not include CVSS scores.
  • KEV: listed in CISA's Known Exploited Vulnerabilities catalog at the time of this run. Treat it as patch first.
  • Exploited: a source in this run reports exploitation, but the CVE is not in KEV.
  • Not reported: no exploitation signal in this run. This does not mean the flaw is safe.
  • Priority: Critical = KEV, or exploitation reported by an official source. High = score 6 or more. Standard = everything else. The suggested order follows the priority.
  • Also named: other CVE IDs in the same entry. They are listed there, not as separate rows.
  • Revision: Microsoft changed an existing entry, for example links or acknowledgements. No new fix is implied.
  • Feed date: the feed gives one time per entry. CVEs in the same entry share it.

This is the Microsoft Security Response Center feed only, not the complete Patch Tuesday list. Use the Security Update Guide for the full list.
