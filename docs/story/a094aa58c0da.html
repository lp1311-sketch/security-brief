Hackers exploit Collabora RCE flaw to backdoor Nextcloud servers

Published: 15 Oct 2026, 20:25 UTC · Priority score 3

Summary

Threat actors are exploiting a critical command execution flaw, now tracked as CVE-2026-110447, in the Collabora Online - Built-in CODE Server app (richdocumentscode) for Nextcloud.

Summary is the feed's excerpt, shortened. It is not a full article.

Why it matters

It concerns CVE-2026-110447: compare the affected versions in the advisory with your inventory. A compromised package or download runs with the rights of whoever installs it. Check whether you use the named package or version, and review installation and endpoint logs. A web shell or code-execution flaw gives an attacker control of the server. Check web server logs and the server for unknown files or processes.
