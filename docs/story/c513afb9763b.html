Rank Math PRO WordPress Plugin Compromised in Supply Chain Attack

Published: 19 Oct 2026, 15:20 UTC · Priority score 1

Summary

Hackers injected malware into Rank Math PRO version 3.0.123 packages distributed between October 15 and October 16. The post Rank Math PRO WordPress Plugin Compromised in Supply Chain Attack appeared first on SecurityWeek.

Summary is the feed's excerpt, shortened. It is not a full article.

Why it matters

A compromised package or download runs with the rights of whoever installs it. Check whether you use the named package or version, and review installation and endpoint logs.

Instructions from the source

Sentences quoted word for word from the original article. Check each one against the article before you act.

  • “All users who installed and activated version 3.0.123 of the plugin during the affected window should treat their websites as compromised and should restore them from a clean backup created before the incident.” — SecurityWeek
  • “Users who cannot restore the site from a backup should delete the Rank Math PRO plugin folder, remove a malicious database entry, block the attacker’s domain rank1cdn[.]com, and find and remove suspicious PHP files and unknown administrator accounts.” — SecurityWeek
  • “Additionally, the attackers could make changes outside the WordPress installation, and site admins should also look for SSH authorized_keys files, crontabs from other system users, suspicious processes, and other locations the web server user has write access to.” — SecurityWeek
  • “After verifying the website is clean, users should change all their passwords and install a clean version of Rank Math PRO.” — SecurityWeek
